HIBERNATE --

ORM - Mapping Object to database table
Why ORM - 
Eliminates boilerplate jdbc code 
Automatic Transcation management 
portability across differnt database 
Reduce sql depedency with hql

JPA - API specification for ORM
Hibernate - popular jpa implementation with advanced feature 
Spring Data JPA - it's a module of spring application 


HIBERNATE Architecutre 
----------------------
Session Factory (creates session ,heavy object , singleton)
Session (interact with DB , light weight , short-lived )
Transcation(Manages commit / rollback )
Query & criteria api (fetching data efficently )
hibernate configuration file (hibernate.cfg.xml)

HIBERNATE LifeCycle 
-------------------
Load Hibernate configuration
create session factory
open session
begin transcation
perform crud operation 
commit transcation
close session
