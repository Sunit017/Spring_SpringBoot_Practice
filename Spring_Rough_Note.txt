What is AOP?
=============
AOP is a programming paradigm that helps you separate cross-cutting concerns (like logging, security, transactions) from your core business logic.
👉 Cross-cutting concerns = code that appears in many places but isn’t part of the main logic.What is AOP?
n real projects, I used AOP for:
Logging: Automatically logging method entries and exits in service layer.
Performance Monitoring: Measuring execution time of methods.
Auditing: Tracking changes in sensitive data updates.
Transaction Management: Using @Transactional (which is built using AOP internally in Spring).

HOW DO YOU HANDLE CACHING IN SPRING BOOT?
Ans - Spring Boot provides declarative caching using the @Cacheable, @CachePut, and @CacheEvict annotations, backed by cache providers like Ehcache, Redis
Annotation	Purpose
@Cacheable	Stores method result in cache
@CachePut	Updates the cache
@CacheEvict	Removes an entry from the cache
